## Overview

Color Gradient Mesh Cloth Canvas is an interactive visual experiment that uses HTML Canvas to render a changing color surface. A 3x3 arrangement of control points can be moved directly, allowing you to see bilinear interpolation respond in real time.

The project provides a hands-on way to examine gradient meshes, cloth-inspired distortion, and canvas-based input handling. It works with both desktop pointer interaction and touch devices, and includes randomized deformation plus an animated waving mode.

---

## What It Includes

- A draggable 3x3 layout containing nine control points.
- Bilinear interpolation for producing the colors between control points.
- A slider for selecting the mesh density.
- Randomized deformation effects for reshaping the surface.
- An optional animated wave effect.
- Mouse-based dragging on desktop browsers.
- Touch interaction on compatible devices.
- In-browser rendering that demonstrates cloth-like movement.

## Using the Canvas

1. Launch the HTML application in a web browser.
2. Select and drag any point in the 3x3 control-point grid.
3. Move the grid-density slider to alter the mesh resolution.
4. Turn on deformation to add randomized movement.
5. Activate waving mode for continuous cloth-like animation.
6. On a phone or tablet, drag the points with touch input instead of a mouse.
